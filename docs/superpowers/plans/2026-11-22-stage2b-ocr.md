# Stage 2b OCR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read pages set aside as `needs_ocr` (scanned PDF pages, photos) with a local docTR engine, on demand, and bring them back into the catalog page by page with their source and confidence.

**Architecture:** A light `ocr.py` holds the engine interface and result types (no torch import); `rendering.py` turns PDF pages and image frames into Pillow images; `quality.assess` learns the OCR page rules; the catalog (schema v3) stores page provenance and an OCR cache keyed by file hash; `ingest.py` applies cached OCR on every assessment and runs the engine only when one is passed; the CLI offers the run at the end of `ingest`. docTR + CUDA PyTorch live in the optional `ocr` extra.

**Tech Stack:** Python ≥ 3.11 (dev machine 3.13.5), SQLite, pypdf, pypdfium2, Pillow, python-doctr 1.1.0 + torch/torchvision (extra), pytest, uv. Run everything from the repository root with `uv run`.

**Spec:** `docs/superpowers/specs/2026-11-22-stage2b-ocr-design.md`

## Global Constraints

- `uv sync` without `--extra ocr` must not install torch, torchvision, python-doctr or opencv. `import localmind` must not import `torch` or `doctr`.
- Nothing leaves the machine except docTR's one-time model download.
- Originals are never modified, moved or deleted.
- Sensitive values are never printed or logged (CLI shows `kind @ page N`).
- The CLI never blocks on input when stdin is not a TTY.
- User decisions (`decisions` table) survive every migration from v2 on.
- `QualityConfig.min_ocr_confidence = 0.70`.
- New reasons: `ocr_low_confidence`, `ocr_no_text`, `ocr_failed`. New page status: `blank`. Page sources: `text_layer`, `ocr`.
- Engine name format: `doctr-<doctr version>/<det_arch>+<reco_arch>`, with `det_arch="db_resnet50"`, `reco_arch="crnn_vgg16_bn"`.
- CLI copy (exact):
  - offer: `{pages} scanned page(s) in {files} file(s) can be read by OCR (~{estimate} on {device}).` then prompt `Run OCR now? [y/N] `
  - not installed: `{pages} scanned page(s) could be read with OCR: uv sync --extra ocr`
  - non-interactive: `{pages} scanned page(s) can be read by OCR: localmind quarantine retry`
  - reminder: `({pages} more scanned page(s) are waiting: localmind quarantine retry)`
- Test suite passes without the extra; the real-docTR test is skipped when `doctr` is not importable.

## Review Focus

1. A phone photo with EXIF orientation 6 (taken sideways) must be read upright — pinned in Task 2 (`test_exif_rotation_is_applied`).
2. Ctrl+C (or a crash) in the middle of a long OCR run must keep the pages already read — the cache is committed per page — pinned in Task 4 (`test_interrupted_run_keeps_pages_already_read`).
3. A truncated / corrupted image file must be quarantined `corrupted`, never crash the run — pinned in Task 2 (`test_corrupted_image_raises_extraction_error`) and Task 4 (`test_corrupted_image_is_quarantined`).
4. A catalog created by stage 2a (v2) holding quarantined `needs_ocr` files with no stored page count must still produce a sensible count in the offer (NULL counts as 1 page) — pinned in Task 3 (`test_pending_counts_unknown_page_count_as_one`).
5. A 100-page scanned PDF must not hold 100 rendered images in memory: rendering is a generator, one page at a time — pinned in Task 2 (`test_render_is_lazy`).

### Task 1: OCR types and page rules

**Files:**
- Create: `src/localmind/ocr.py`
- Modify: `src/localmind/quality.py`, `src/localmind/extractors.py` (`ExtractedText` gains `ocr`)
- Test: `tests/test_ocr.py`, `tests/test_quality.py`

**Interfaces:**
- Produces (in `ocr.py`, stdlib imports only):
  - `@dataclass(frozen=True) class OcrPage: text: str; confidence: float; engine: str` — `confidence < 0` means the engine failed on that page.
  - `class OcrEngine(Protocol): name: str; device: str; def read(self, image: "PIL.Image.Image") -> tuple[str, float]` (text, page confidence)
  - `class OcrUnavailable(RuntimeError)`
  - `def page_confidence(words: Sequence[tuple[str, float]]) -> float` — mean of word confidences weighted by `len(word)`; `0.0` for no words.
  - `def ocr_available() -> bool` — `importlib.util.find_spec("doctr") is not None`, without importing it.
  - `def load_engine() -> OcrEngine` — stub raising `OcrUnavailable("OCR not installed: uv sync --extra ocr")` until Task 6.
- Produces (in `extractors.py`): `ExtractedText.ocr: Mapping[int, OcrPage]` defaulting to an empty mapping (1-based page → OCR result; never mutated).
- Produces (in `quality.py`):
  - `Reason.OCR_LOW_CONFIDENCE = "ocr_low_confidence"`, `Reason.OCR_NO_TEXT = "ocr_no_text"`, `Reason.OCR_FAILED = "ocr_failed"`
  - `QualityConfig.min_ocr_confidence: float = 0.70`
  - `PageVerdict` gains `source: str = "text_layer"`, `ocr_engine: str | None = None`, `ocr_confidence: float | None = None`, and property `is_blank` (`reason is Reason.OCR_NO_TEXT`).
  - `Assessment.has_set_aside` ignores blank pages.
  - `def needs_ocr_pages(extracted: ExtractedText, config: QualityConfig) -> frozenset[int]` — the pages the text-layer rules mark `needs_ocr` (one implementation shared with `_page_reason`).
  - `extracted.kind` may now be `"image"`: same text-layer rules as `"pdf"`.

### Task 3: Catalog schema v3

**Files:**
- Modify: `src/localmind/catalog.py`
- Test: `tests/test_catalog.py`

**Interfaces:**
- Consumes: `PageVerdict` fields and `OcrPage` (Task 1).
- Produces:
  - `SCHEMA_VERSION = 3`. `pages` gains `source TEXT NOT NULL DEFAULT 'text_layer'`, `ocr_engine TEXT`, `ocr_confidence REAL`; `status` accepts `'blank'`. `files` gains `page_count INTEGER`. New table `ocr_cache(file_hash TEXT NOT NULL, page_no INTEGER NOT NULL, engine TEXT NOT NULL, text TEXT NOT NULL, confidence REAL NOT NULL, created_at TEXT NOT NULL, PRIMARY KEY (file_hash, page_no, engine))`.
  - Migration: v1 → drop and recreate every table **except `decisions`**; v2 → v3 in place, in one transaction. SQLite cannot alter a CHECK constraint: rebuild `pages` (`CREATE TABLE pages_new …; INSERT … SELECT …; DROP TABLE pages; ALTER TABLE pages_new RENAME TO pages`) with `PRAGMA foreign_keys=OFF` around it, and recreate its index.
  - `add_document` stores `source`, `ocr_engine`, `ocr_confidence`, and status `blank` for blank pages.
  - `record_quarantine(path, file_hash, size_bytes, reason, page_count: int | None = None)`.
  - `ocr_cached(file_hash: str, page_no: int) -> OcrPage | None` (most recent entry, any engine).
  - `store_ocr(file_hash: str, page_no: int, page: OcrPage) -> None` (upsert, commits immediately).
  - `ocr_candidates(under: Path | None = None) -> list[FileRecord]` — files `quarantined` with reason `needs_ocr`, or `indexed` whose document has a page set aside with reason `needs_ocr`; `under` filters like `retry_candidates`.
  - `@dataclass(frozen=True) class PendingOcr: pages: int; files: int` and `ocr_pending(under: Path | None = None) -> PendingOcr` — set-aside `needs_ocr` pages of indexed files + `page_count` of quarantined `needs_ocr` files (NULL → 1).
  - `Stats` gains `ocr_pages: int`, `blank_pages: int`. `SetAsidePage` gains `ocr_confidence: float | None`.

### Task 4: OCR in the ingestion path

**Files:**
- Modify: `src/localmind/ingest.py`, `src/localmind/__init__.py`
- Test: `tests/test_ocr_ingest.py` (new), `tests/test_ingest.py`

**Interfaces:**
- Consumes: Tasks 1–3.
- Produces:
  - `ingest(root, catalog, config=…, engine: OcrEngine | None = None, on_ocr_page: Callable[[Path, int], None] | None = None) -> IngestReport`
  - `retry(catalog, config=…, under=None, engine=None, on_ocr_page=None) -> IngestReport`
  - `run_ocr(catalog, engine: OcrEngine, config=…, under: Path | None = None, on_ocr_page=None) -> IngestReport` — re-processes `catalog.ocr_candidates(under)` with `force=True` (missing files → `MISSING`, like `retry`).
  - `apply_decision`: signature unchanged; uses cached OCR, no engine.
  - In `_process`, after `extract` and before `assess`: for each page in `needs_ocr_pages(extracted, config)`: cached → use it; else if `engine` → `on_ocr_page(path, page_no)`, render that page (`render_pages`, one at a time), `engine.read`, `catalog.store_ocr`, use it; an engine exception (`Exception`, not `KeyboardInterrupt`) → `OcrPage("", -1.0, engine.name)`, not cached, logged with the exception class only. Then `assess(replace(extracted, ocr=...))`. A cache entry exists only for pages that were read successfully.
  - `_file_level_reason` drops the image rule. Quarantine records pass `extracted.page_count` when an extraction happened.
  - `localmind.__init__` exports `run_ocr`, `OcrEngine`, `OcrPage`, `ocr_available`, `load_engine`.

Test helper in `tests/test_ocr_ingest.py`: `FakeEngine(script: list[tuple[str, float]], raise_on: int | None = None, exc: type[BaseException] = RuntimeError)` with `name = "fake-1"`, `device = "GPU"`, `calls` counter; `read` returns the next scripted result, or raises `exc` on call number `raise_on`.

### Task 5: CLI offer, retry with OCR, listings

**Files:**
- Modify: `src/localmind/cli.py`
- Test: `tests/test_cli.py`

**Interfaces:**
- Consumes: `ocr_available`, `load_engine`, `OcrUnavailable` (Task 1), `run_ocr`, `retry(engine=…)` (Task 4), `ocr_pending` (Task 3).
- Produces:
  - `ingest PATH... [--ocr | --no-ocr]` (mutually exclusive); `quarantine retry [PATH] [--no-ocr]`.
  - Module-level `_is_interactive() -> bool` (`sys.stdin.isatty()`) and `_ask(prompt: str) -> bool` (`input()`; `y`, `yes`, `o`, `oui`, any case → True; `EOFError` → False). Tests monkeypatch both, plus `localmind.cli.ocr_available` and `localmind.cli.load_engine`.
  - `_estimate(pages: int, device: str) -> str` with `SECONDS_PER_PAGE = {"GPU": 0.5, "CPU": 5.0}`: under 60 s → `"N s"`, else `"N min"` rounded up.
  - Offer logic, run once after all ingest reports, scope = the ingested paths:
    1. `pending` = sum of `ocr_pending(p)` over the paths; `others = ocr_pending().pages - pending.pages`.
    2. `pending.pages == 0` → print the reminder if `others > 0`; stop.
    3. not `ocr_available()` → not-installed line; stop.
    4. `--no-ocr` → stop. `--ocr` → run. Interactive → `engine = load_engine()`, offer line (device from `engine.device`), `_ask`. Non-interactive → non-interactive line; stop.
    5. Run = `run_ocr(catalog, engine, under=p)` per path with `on_ocr_page` printing `  OCR page {k}/{pending.pages}: {path.name} p.{n}`, then the usual report; then the reminder if `others > 0`.
  - `quarantine retry` passes `load_engine()` when `ocr_available()` and not `--no-ocr`.
  - `quarantine` listing: `page 2 [ocr_low_confidence 58 %]` when a confidence is known. `stats` adds `ocr pages:` and `blank pages:` (labels padded to 17 columns like the others).
